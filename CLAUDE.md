## Дополнительно для Claude Code

- Независимые задачи по разным проектам решения раскладывай по сабагентам и запускай одним
  сообщением. Правки в одних и тех же файлах параллельно не ведутся: либо развести по проектам,
  либо `isolation: "worktree"`.
- Только последовательно и одним агентом: `contract/`, `Directory.Build.props`,
  `Directory.Packages.props`, `context/` — конфликт там дороже выигрыша.
- Сабагенту с `isolation: "worktree"` приватный контекст недоступен: в свежем ворктри нет ссылки
  `context/private`. Задачи про адреса, публикацию и подпись так не запускать — агент не увидит
  значений и начнёт их выдумывать.
