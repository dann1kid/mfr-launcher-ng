# Решения клиента

Как устроен клиент и почему так. Статус и история живут здесь, не в коде и не в требованиях
(раздел «Требования к клиенту» в `AGENTS.md`).

- **Адреса — только файл адресов.** Весь `addresses.json` вшивается в exe ресурсом, код адресов
  не содержит. Клиент берёт из него боевой контур; другой контур подключается `launcher.json`
  рядом с exe. Смена адреса — правка одного файла, для любого контура собирается тот же исходник.
- **Lock-файлы описывают сборку без RID.** Restore конвейера идёт без RID в locked-mode;
  публикация под win-x64 восстанавливает RID-граф сама, и её правки lock-файлов не коммитятся.
  Lock'и остаются едиными для проверки и не зависят от платформы публикации.
- **Повторное применение опций переживает сбой.** Список вариантов «Группа|Вариант» хранится в
  состоянии клиента до применения и снимается после успеха: сбой или выход из клиента его не
  теряют, повтор задачи доводит применение до конца. Совпадение считается в обоих пространствах
  путей — пакета и установки, — граница пакета проходит по группе манифеста.
- **Регион выбирается до первого запроса.** Сохранённый выбор применяется без замера; без выбора
  замеряется `/ping` обоих регионов. Проба активации и опрос ходят в выбранный регион, а не в
  умолчальный.
- **Таймаут HTTP отличён от отмены.** У таймаута внутреннее исключение `TimeoutException`,
  у паузы игрока его нет: таймаут — ошибка связи с повтором, отмена проходит насквозь. Механизм
  один на всех уровнях — запросы, манифесты, файлы.
- **В ходе задачи кнопка принадлежит задаче.** Пока задача идёт, события опроса не возвращают
  главной кнопке действие: вторая задача кликом не запускается, состояние связи не затирает ход.
- **Тяжёлая работа — вне UI-потока.** Сверка целостности хеширует сборку в фоне, применение
  опций и удаление пакета копируют и удаляют файлы рабочими задачами; окно отвечает на клики
  весь проход, прогресс идёт пофайлово.
- **Единицы объёма соответствуют значению.** Строка состояния показывает готовое: проверенные
  на диске файлы и докачанное входят в числитель, подпись ступени совпадает с делителем.
