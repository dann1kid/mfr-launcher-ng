# Образ заданий конвейера

Собирается ручным заданием `image:ci` в GitLab CI. Содержит SDK (закреплён в
`global.json`) и прогретый кеш пакетов, чтобы сборка в конвейере шла без сети.

После добавления или смены пакета, lock-файла или SDK задание `build:dotnet`
падает с именем недостающего пакета — пока человек не пересоберёт образ.
